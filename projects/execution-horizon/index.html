Execution-horizon selection

Learned-model model predictive control · Research in progress

Research question

With a fixed prediction horizon, when can executing a longer action prefix improve closed-loop performance?

Approach

This project studies the mechanism behind execution-horizon preferences in learned-model MPC, then asks how finite-data uncertainty changes those preferences.

Current direction

  • Characterize conditions under which longer execution helps.
  • Study statistical uncertainty in the paired cost difference between execution choices.
  • Validate the analysis with the full learned multistep predictor.

The goal is to connect model learning and execution decisions through conditions that explain when an execution preference is statistically reliable.
